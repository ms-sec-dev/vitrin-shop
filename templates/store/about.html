درباره پروژه

ویترین؛ یک فروشگاه فارسی کامل

نمونه‌کاری برای نمایش توانایی در طراحی رابط کاربری، توسعه بک‌اند و استقرار پروژه با داکر.

چه چیزی در این پروژه پیاده شده؟

ویترین یک فروشگاه اینترنتی نمونه است که از صفر با جنگو ساخته شده؛ بدون وابستگی به سرویس‌های خارجی و با تصاویر و فونت لوکال، بنابراین آفلاین هم کامل کار می‌کند. رابط کاربری راست‌به‌چپ، واکنش‌گرا و با جزئیات ریز طراحی شده تا تجربه‌ای نزدیک به یک فروشگاه واقعی ارائه دهد.

جستجو و فیلتر

جستجو در نام، برند و توضیحات، فیلتر دسته‌بندی و مرتب‌سازی قیمت و امتیاز.

سبد خرید AJAX

افزودن، تغییر تعداد و حذف بدون بارگذاری صفحه با به‌روزرسانی زنده مبالغ.

سفارش واقعی در دیتابیس

فرم معتبرسنجی‌شده، ثبت سفارش، کد پیگیری و نمایش در پنل ادمین.

اعداد و تاریخ فارسی

نمایش قیمت‌ها با ارقام فارسی و تاریخ شمسی برای سفارش‌ها.

واکنش‌گرا و RTL

طراحی موبایل‌فرست با منوی کشویی، نوار پایین موبایل و گرید تطبیقی.

آماده استقرار

Dockerfile و docker-compose، Gunicorn و WhiteNoise برای اجرای ساده روی هر سیستم.

پشته فناوری

Python 3DjangoSQLite HTML5CSS3JavaScript GunicornDocker

اجرای سریع با داکر

docker compose up --build

سپس آدرس http://localhost:8000 را باز کنید.

اجرای لوکال

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed
python manage.py runserver
